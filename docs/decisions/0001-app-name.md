# 0001 — App name: Clipo

Status: accepted

**Decision.** The app is called Clipo. The repository keeps the name `clipboard-manager`.

**Why.** Short, easy to type and fits a menu-bar or tray label.

**Consequences.** The CI scheme name `ClipboardManager` in `.github/workflows/ci.yml` becomes `Clipo` when the Xcode project is created (step 2.1).
